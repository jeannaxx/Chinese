# HSK 3.0 ภาษาไทย

เว็บท่องศัพท์ภาษาจีน HSK 3.0 ระดับ 1–6 (5,334 คำ) พร้อมพินอินแบบสีวรรณยุกต์ ความหมายภาษาไทยและภาษาอังกฤษ ไม่มีหลังบ้าน เปิด `index.html` ได้เลย

## โหมด
- **คำศัพท์**: ค้นหาได้ทั้งอักษรจีน พินอิน (ไม่ต้องใส่วรรณยุกต์) และภาษาไทย กรองตามระดับ HSK 1–6 บันทึกคำ ★ และฟังเสียง
- **แฟลชการ์ด**: ดูอักษรจีน นึกคำอ่านกับความหมาย แล้วแตะเพื่อดูเฉลยพร้อมประโยคตัวอย่าง
- **แบบทดสอบ**: 10 ข้อ เลือกความหมายที่ถูกต้อง (สลับตอบเป็นไทยหรือ English ได้)
- **พินอิน**: ดูความหมายไทยแล้วพิมพ์พินอิน (ไม่ต้องใส่วรรณยุกต์)
- **ประโยค**: แตะเรียงคำจีนให้เป็นประโยคตามคำแปลไทย

สีวรรณยุกต์: แดง = เสียง 1 · เขียว = เสียง 2 · น้ำเงิน = เสียง 3 · ม่วง = เสียง 4 · เทา = เสียงเบา

ความคืบหน้าเก็บในเบราว์เซอร์ของผู้ใช้ (localStorage) เสียงอ่านใช้ Web Speech API ของเบราว์เซอร์ (zh-CN)

## ข้อมูล
- คำศัพท์ พินอิน ชนิดคำ และระดับ: หลักสูตรสอบ HSK 3.0 (新版HSK考试大纲) ที่ 中外语言交流合作中心 เผยแพร่เมื่อ พ.ย. 2025 ข้อมูลถอดโดย [harukicoder/hsk30](https://github.com/harukicoder/hsk30)
- ระดับของแต่ละคำคือระดับที่คำนั้นเริ่มปรากฏ คำศัพท์สะสมตามเอกสารทางการ: HSK1 300 · HSK2 500 · HSK3 1,000 · HSK4 2,000 · HSK5 3,600 · HSK6 5,400
- ความหมายภาษาไทย ภาษาอังกฤษ และประโยคตัวอย่าง: เขียนเพิ่มสำหรับเว็บนี้ (อังกฤษอ้างอิง [CC-CEDICT](https://cc-cedict.org/) ผ่าน complete-hsk-vocabulary) ยังไม่ได้ผ่านการตรวจทานจากผู้เชี่ยวชาญ แก้ไขได้ใน `data/hsk.js`
